# 协议、安全及报告格式

协议采用一请求一响应的 JSON 文档，不是 JSONL 或网络服务。版本 1 的字段、效应族、默认值和计数域以 README 为准。错误消息用于开发定位，可能包含用户提供的 ID/字段名；应用集成者应自行决定是否记录，不能把不可信消息插入 HTML。

所有统计计算在 MoonBit 中完成。非有限输入、零/负方差、重复 ID、未知字段、重复键、计数小数、混合效应族、无效推断组合、非法输出选项均失败。解析错误不回显原始请求。错误码 invalid_input 同时涵盖统计域错误和数值不可表示，不提供细分稳定子码。程序断言或内存耗尽不属于被保证转化的输入错误。

Node 入口有界地读最多 1 MiB，不执行请求内命令、不选择输出路径、不发网络请求。文件入口不能替调用者授权本地路径；它只是用户显式指定文件。stdin 长时间不结束时等待 EOF，外围服务需要自行设置超时、并发与文件权限。仅限制大小不等于服务端完整拒绝服务防护。

CSV 列顺序：type,id,group,effect,variance,lower,upper,weight,q,tau2。study 行 variance 为采样方差，q 为该研究残差贡献；pooled 行 variance 为已选推断的标准误平方，q 为残差总和；weight 列为比例，pooled 为 1。危险文本加单引号，CSV 用于展示，原始标签请使用 JSON。电子表格的行为并无统一保证，导入时仍应按文本处理标签列。

SVG 的横轴始终是输入效应的加性尺度，包括 log 比值。输出使用数字生成坐标、内部固定颜色、XML 转义文本，无 script、foreignObject、URL 或事件属性。非法 XML 控制字符失败；标题最多 256 单元。SVG 没有外部资源依赖。森林图表达估计与区间，不自动选择研究或判定离群研究。
