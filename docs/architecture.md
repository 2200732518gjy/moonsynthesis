# 数据流与实现边界

输入经 study/两组转换器构建不可修改字段的 Study。JSON 先执行大小、深度、重复键与字段 allowlist，再进行类型、计数、同效应族和数学域校验。Request 可由库调用者构造，execute 再校验选项及计算预算。

pool_at 把权重缩放为 min(v+tau²)/(v+tau²)，计算归一化权重、估计、采样方差和残差 Q。DL 基于固定权重 Q 和校正项，非正结果截为零；PM 先检查 Q(0)<=df 的零边界，再倍增括区间并二分。每个子集重估 tau²，缓存不参与数值语义。

analyze 根据模型和推断选项构造置信与预测区间。研究级区间只用研究采样方差。GroupComparison 的 Q 分解始终使用固定权重，避免混用每组随机权重破坏恒等式。

协议层调用同一组公开 API。CSV 和 SVG 直接使用拟合结果，没有第二套统计实现。Node 适配器只完成有界输入及 UTF-8 解码，既不算权重，也不处理统计错误。

复杂度主要来自 PM 重拟合。唯一性校验 O(k²)，PM 最多 160 次二分及有界倍增；留一法与累积为多个子集分别拟合。公开 API 和协议均限制重拟合规模，不提供并行全局状态或隐式网络访问。
